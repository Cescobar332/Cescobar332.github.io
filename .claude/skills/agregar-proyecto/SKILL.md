# Añadir o actualizar un proyecto

1. Leer el README del proyecto (en `../<carpeta>` si está clonado, o en GitHub) para sacar: qué problema resuelve, tecnologías y un resultado concreto o métrica.
2. Pedir o tomar una captura; guardarla en `img/` con nombre en minúsculas con guiones.
3. Añadir una entrada en `featuredRepos` de `js/main.js` con descripción en `es` y `en`. La descripción dice QUÉ hace y CON QUÉ, en una o dos frases, sin adjetivos vacíos.
4. Orden: el proyecto más fuerte primero (hoy: RAG, luego expense-tracker).
5. Verificar con `/preview` en ambos idiomas y en móvil.
6. Explicar al usuario en lenguaje sencillo qué se cambió y dónde.
